# Security Policy

## Reporting a vulnerability

Please report any security issue privately through the project maintainer or the designated security contact for this deployment.

## Supported versions

This project is intended for internal use and is not a public product. Security updates are applied on a best-effort basis for the current main branch.

## Security expectations

- Keep dependencies up to date.
- Do not expose credentials or session secrets in source control.
- Use environment variables and deployment secret stores for runtime configuration.
- Protect admin endpoints and audit log access.
